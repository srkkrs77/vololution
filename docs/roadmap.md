**Сборка:** Evolution CMS 1.4.37 (Community Edition)  
**Философия:** эволюция, не революция. Глубина там, где нужно.

## Этап 1 — SEO + живой поиск

### 1.1. SEO-плагин — ✅ ВЫПОЛНЕНО

**Что сделано (пакет `seoVolo`):**
- `canonical` — авто + переопределение через TV.
- `meta description` — из TV / description / introtext / content (fallback).
- `meta keywords` — опционально (TV есть, вывод отключён).
- Open Graph — 7 тегов.
- Twitter Cards — 4–6 тегов.
- Schema.org JSON-LD — Organization, WebSite, WebPage, Article, Product, Service, FAQPage, BreadcrumbList.
- `hreflang` — включается настройкой, работает с EvoBabel.
- 11 TV на отдельной вкладке «SEO» в форме документа.
- Сниппет `seoVolo` + плагин `seoVolo` (авто-привязка TV к новым шаблонам).

**Отложено:**
- TV-поле с индикатором длины description ⭐ (нужен widget TV).
- `robots.txt` из админки.

**Детали:** `CHANGELOG.md`, раздел 15.

### 1.2. Живой поиск (AJAX autocomplete) — ⬜ СЛЕДУЮЩАЯ ЗАДАЧА

**Что должно быть:**
- Поле ввода в шапке сайта.
- Результаты под полем по мере ввода (без перезагрузки).
- Настраиваемый вывод через параметры сниппета:
  - только текст (заголовок + сниппет);
  - + картинка;
  - + категория;
  - + цена (для магазина).
- Подсветка совпадений.
- Клавиатурная навигация (стрелки вверх/вниз, Enter).
- Кнопка «Показать все результаты» → переход на страницу поиска.

**Технически:** сниппет + AJAX-endpoint + JS.

## Этап 3 — Социальный слой

### 3.1. Комментарии — ⬜

- Только для авторизованных пользователей.
- Модерация (пре-модерация / пост-модерация — настройка).
- Капча — опционально.
- Ответы на комментарии (вложенность).
- Уведомления по email.
- Антиспам (задержка между комментариями, чёрный список слов).

### 3.2. Авторизация пользователей — ⬜

- Email + пароль (регистрация, вход, восстановление пароля).
- Соцсети: **VK, Google, Facebook, Яндекс, Mail.ru** (через OAuth).
- Профиль пользователя (аватар, имя, контакты).
- Роли: гость, пользователь, модератор, администратор.

**Технически:** модуль + плагин + интеграция с OAuth-провайдерами.

## Этап 5 — Магазин — ⬜

- Каталог товаров (категории, фильтры, сортировка).
- Карточка товара (характеристики, галерея, отзывы).
- Корзина.
- Оформление заказа (гость + залогиненный).
- **Платёжные системы:** ЮKassa, Robokassa, Тинькофф.
- **Доставка:** СДЭК, Почта России, самовывоз.
- Управление заказами в админке.
- Экспорт заказов в CSV/Excel.
- Промокоды и скидки.

**Технически:** модуль + сниппеты + интеграция с API платёжек.

**Вдохновение:** функционал EasyNetShop (не SaaS-конструктор, а полноценный магазин на своём сайте).

## Этап 7 — Инфраструктура

### 7.1. Модуль бэкапа — ⬜
- Автоматический бэкап БД + файлов по расписанию.
- Хранение локально + отправка в облако (Яндекс.Диск, Google Drive).
- Восстановление одной кнопкой.

### 7.2. PDO-адаптер — ⬜
- Замена `mysqli` на PDO в `dbapi`.
- Поддержка PostgreSQL, SQLite (в перспективе).

### 7.3. Свой установщик — ⬜
- Современный, с PHP 8.5 из коробки.
- Графический интерфейс.
- Проверка требований сервера.
- Автоматическое создание БД.

### 7.4. Закрытие CSRF-дыр — 🟡 В РАБОТЕ
- Ротация токенов на login/logout.
- Origin/Referer check.
- Защита connector'ов модулей.
- Убрать дублирование JS в `header.inc.php`.

**Подробности:** `CHANGELOG.md`, раздел 9.1.

### 7.5. Свой Extras-модуль (Store) — ✅ ВЫПОЛНЕНО
- Веб-морда для установки пакетов.
- Отвязка от `extras.evo.im`.
- Источник: `github.com/srkkrs77/vololution/packages`.

**Детали:** `CHANGELOG.md`, раздел 14.

### 7.6. Отвязка от обновлений Evo — ✅ ВЫПОЛНЕНО
- Плагины Updater и OutdatedExtrasCheck отключены.
- RSS-ленты CE (`security-fix` и `releases.atom`) оставлены — источник уведомлений.
- Автообновление не запускается.
- Обновление CE — вручную по `docs/patches-manifest.md`.
