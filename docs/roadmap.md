**Сборка:** Evolution CMS 1.4.37 (Community Edition)

## Этап 1 — SEO + живой поиск

### 1.1. SEO-пакет seoVolo — ✅ ВЫПОЛНЕНО

**Что сделано:**
- Сниппет `seoVolo` — генерация мета-тегов
- 11 TV на вкладке SEO в форме документа
- Плагин `seoVolo` — автосоздание настроек + привязка TV к шаблонам
- Модуль `seoVolo Settings` — форма управления настройками
- Мультиязычность (ru/en/de)
- Кнопка Browse для лого и OG-картинки

**Что генерируется:**
- `<title>` с fallback
- `<meta description>` с fallback и обрезкой до 160
- `<link rel="canonical">` — авто или через TV
- Open Graph — 7 тегов
- Twitter Cards — 4–6 тегов
- Schema.org JSON-LD: Organization, WebSite, WebPage, Article, NewsArticle, BlogPosting, Product, Service, FAQPage, BreadcrumbList
- Hreflang (через EvoBabel, отключаемый)
- `<meta name="robots">` — при `noindex`

**Отложено:**
- Индикатор длины description ⭐ — через виджет TV (Evo `@output_widget`). Плагинный подход не сработал.
- `sitemap_*` TV — созданы, но DLSitemap нужно дополнительно настроить через параметры сниппета.
- Schema.org Product — без `seo_sku`, `seo_price`.

**Детали:** `CHANGELOG.md`, раздел 15.

### 1.2. Живой поиск (AJAX autocomplete) — ⬜ СЛЕДУЮЩАЯ ЗАДАЧА

**Что должно быть:**
- Поле ввода в шапке сайта.
- Результаты появляются под полем по мере ввода (без перезагрузки).
- Настраиваемый вывод через параметры сниппета:
  - только текст (заголовок + сниппет);
  - + картинка;
  - + категория;
  - + цена (для магазина).
- Подсветка совпадений.
- Клавиатурная навигация (стрелки вверх/вниз, Enter).
- Кнопка «Показать все результаты» → переход на страницу поиска.

**Технически:** сниппет + AJAX-endpoint + JS. Использовать `evoSearch` (уже установлен) как бэкенд поиска.

## Этап 3 — Социальный слой

### 3.1. Комментарии — ⬜

- Только для авторизованных пользователей.
- Модерация (пре-модерация / пост-модерация — настройка).
- Капча — опционально.
- Ответы на комментарии (вложенность).
- Уведомления по email.
- Антиспам (задержка между комментариями, чёрный список слов).

### 3.2. Авторизация пользователей — ⬜

- Email + пароль (регистрация, вход, восстановление пароля).
- Соцсети: **VK, Google, Facebook, Яндекс, Mail.ru** (через OAuth).
- Профиль пользователя (аватар, имя, контакты).
- Роли: гость, пользователь, модератор, администратор.

**Технически:** модуль + плагин + интеграция с OAuth-провайдерами.

## Этап 5 — Магазин — ⬜

- Каталог товаров (категории, фильтры, сортировка).
- Карточка товара (характеристики, галерея, отзывы).
- Корзина.
- Оформление заказа (гость + залогиненный).
- **Платёжные системы:** ЮKassa, Robokassa, Тинькофф.
- **Доставка:** СДЭК, Почта России, самовывоз.
- Управление заказами в админке.
- Экспорт заказов в CSV/Excel.
- Промокоды и скидки.

**Технически:** модуль + сниппеты + интеграция с API платёжек.

**Вдохновение:** функционал EasyNetShop (не SaaS-конструктор, а полноценный магазин на своём сайте).

## Этап 7 — Инфраструктура

### 7.1. Модуль бэкапа — ⬜
- Автоматический бэкап БД + файлов по расписанию.
- Хранение локально + отправка в облако (Яндекс.Диск, Google Drive).
- Восстановление одной кнопкой.

### 7.2. PDO-адаптер — ⬜
- Замена `mysqli` на PDO в `dbapi`.
- Поддержка PostgreSQL, SQLite (в перспективе).

### 7.3. Свой установщик — ⬜
- Современный, с PHP 8.5 из коробки.
- Графический интерфейс.
- Проверка требований сервера.
- Автоматическое создание БД.

### 7.4. Закрытие CSRF-дыр — 🟡 В РАБОТЕ

**4 задачи (см. `CHANGELOG.md`, раздел 9.1):**
- **Задача A.** Ротация токенов на login/logout (4 точки).
- **Задача B.** Origin / Referer check в `checkCsrfToken()`.
- **Задача C.** Защита connector'ов модулей (Store, MultiTV, evoSearch, editDocs).
- **Задача D.** Убрать дублирование JS в `manager/includes/header.inc.php`.

**Критерий готовности:**
- Logout → старый токен 403, Login → новый токен в meta.
- POST с чужого Origin → 403 + запись в Event log.
- Connector без токена → 403.
- В `header.inc.php` — один CSRF-JS-блок.

### 7.5. Свой Extras-модуль (Store) — ✅ ВЫПОЛНЕНО
- Веб-морда для установки пакетов.
- Отвязка от `extras.evo.im`.
- Источник: `github.com/srkkrs77/vololution/packages`.

**Детали:** `CHANGELOG.md`, раздел 14.

### 7.6. Отвязка от обновлений Evo — ✅ ВЫПОЛНЕНО
- Плагины Updater и OutdatedExtrasCheck отключены.
- RSS-ленты CE (`security-fix` и `releases.atom`) оставлены — источник уведомлений.
- Автообновление не запускается.
- Обновление CE — вручную по `docs/patches-manifest.md`.

### 7.7. CLI-скрипт для патчей — ⬜ МОЖНО ПИСАТЬ

**Назначение:** автоматизировать накат патчей на ядро при обновлении CE.

**Что делает:**
- Читает `docs/patches-manifest.md`.
- Для каждого патча: находит паттерн в файле ядра, применяет замену.
- Отчёт: что применено, что не найдено (значит CE изменил файл).
- Откат при ошибке.

**Когда нужен:** патчей много (десятки), накат вручную занимает часы. CLI-скрипт — минуты.

**Почему не плагин:** плагин висит в рантайме на каждом запросе, замедляет, хрупок. CLI — разовая операция, не влияет на работу сайта.
