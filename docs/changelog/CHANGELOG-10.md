text

### 11.2. Принципы

1. **Эволюция, не революция.** Постепенная модернизация, работающая система не ломается.
2. **Глубина там, где нужно.** CSRF и безопасность — правим ядро. Остальное — точечно.
3. **Свои дополнения — сразу на PHP 8.5.** Не тащим legacy.
4. **Документируем каждый патч.** `CHANGELOG.md` + `docs/patches-manifest.md`.
5. **Плагины и сниппеты — где можно, ядро — где нужно.**
6. **Простота Evo для разработчика сохраняется.** Без Laravel, Twig, Blade, SPA, AJAX-first.
7. **Обратная совместимость с extras — критична.**
8. **Классические формы по умолчанию.** AJAX — только там, где без него нельзя.
