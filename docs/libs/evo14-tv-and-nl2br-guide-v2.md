# Шпаргалка по Evolution CMS 1.4 (VoloLution CMS): TV-параметры, ManagerManager и вывод переносов строк

Актуальная рабочая конфигурация для настройки дополнительных полей в админке, их переноса в нужную часть формы редактирования и корректного вывода на сайте.

---

## 1. Архитектура ManagerManager в сборке VoloLution CMS (Evo 1.4)

1. **Где хранятся правила:** В этой сборке плагин `ManagerManager` читает правила не из файлов на сервере, а из **чанка `mm_rules`** (`Элементы → Управление элементами → Чанки → mm_rules`).
2. **Контекст выполнения:** Чанк `mm_rules` выполняется в обычном HTML/PHP-контексте, поэтому скрипты внутри него подключаются напрямую через `echo '<script>...</script>';` (без использования `$modx->Event->output()` или `$mm_output`).
3. **Штатные функции и JS:**
   * Штатная функция `mm_moveFieldsToTab($fields, $tabId, $roles, $templates)` переносит поля на другую вкладку (например, на кастомную вкладку через `mm_createTab`), но не умеет ставить их после конкретного поля внутри вкладки «Общие» (`general`).
   * Чтобы поставить TV-параметры строго под нужным стандартным полем (например, после `description`), используется небольшой ванильный JS-скрипт на событие `DOMContentLoaded`.

## 2. Итоговая схема полей для Hero-блока и слайдера

Чтобы контент-менеджер мог удобно редактировать заголовок с курсивом и переносами строк, а также текст слайдера, используются **3 TV-параметра** типа `Текстовая область` (`textarea`):

| Имя TV-параметра | Тип ввода | Назначение |
| :--- | :--- | :--- |
| **`hero-title`** | Текстовая область (`textarea`) | Основная часть заголовка `<h1>` (обычное начертание). |
| **`hero-title-em`** | Текстовая область (`textarea`) | Вторая часть заголовка `<h1>` (оборачивается в `<em>` + желтая точка). |
| **`slider-content`** | Текстовая область (`textarea`) | Основной текстовый блок под заголовком / в слайдере. |

*Важно:* Для всех созданных TV-параметров во вкладке **«Доступ шаблонов»** должна стоять галочка напротив нужного шаблона (например, `home`).

## 3. Код для чанка `mm_rules` (перенос полей под «Описание»)

Добавьте этот блок в самый конец чанка **`mm_rules`**:

```php
// --- Перенос TV заголовка и текста под поле description ---
echo '<script>
document.addEventListener("DOMContentLoaded", function() {
    var descInput = document.querySelector("[name='description']");
    if (!descInput) return;
    var target = descInput.closest(".form-row, .row, tr");
    
    // Поля указываются в обратном порядке (снизу вверх), 
    // чтобы в админке они выстроились сверху вниз: hero-title -> hero-title-em -> slider-content
    ["slider-content", "hero-title-em", "hero-title"].forEach(function(name) {
        var elems = document.querySelectorAll("small, span, label, div");
        for (var i = 0; i < elems.length; i++) {
            if (elems[i].textContent.trim() === "[*" + name + "*]") {
                var row = elems[i].closest(".form-row, .row, tr");
                if (row && target && row !== target) {
                    target.parentNode.insertBefore(row, target.nextSibling);
                }
                break;
            }
        }
    });
});
</script>' . "
";
```

### Имена стандартных полей для вставки после них (`target`)
Если нужно поставить TV-параметры после другого системного поля, замените `[name='description']` на нужное имя:
* `pagetitle` — Заголовок
* `longtitle` — Расширенный заголовок
* `description` — Описание
* `alias` — Псевдоним
* `introtext` — Аннотация

## 4. Переносы строк (`Enter` → `<br>`) во фронтенде

В Evo 1.4 встроенный модификатор `:nl2br` в прямом теге `[*...*]` может не обрабатываться. Самое надежное решение — создать собственный однострочный сниппет.

### Шаг 1. Создание сниппета `nl2br`
1. Перейдите: **Элементы → Управление элементами → Сниппеты → Новый сниппет**.
2. **Название сниппета:** `nl2br`
3. **Код сниппета:**
```php
<?php
return nl2br($input);
```

### Шаг 2. Вывод в HTML-шаблоне
Оборачивайте теги `[*...*]` в вызов сниппета `[[nl2br? &input=`...`]]`:

```html
<h1 class="hero-title">
    [[nl2br? &input=`[*hero-title*]`]]<br>
    <em>[[nl2br? &input=`[*hero-title-em*]`]]</em><span class="dot-yellow">.</span>
</h1>

<div class="hero-text">
    [[nl2br? &input=`[*slider-content*]`]]
</div>
```

**Как это работает:** Любое нажатие `Enter` внутри текстового поля в админке автоматически превращается в тег `<br />` на сайте.

## 5. Полезные приемы для чанка `mm_rules` на будущее

### Создание отдельной вкладки и перенос полей в неё
```php
mm_createTab('Название вкладки', 'custom_tab', '', '', '', '');
mm_moveFieldsToTab('tv_name_1,tv_name_2', 'custom_tab', '', '');
```

### Скрытие лишних полей для контент-менеджеров (всех, кроме администраторов с ролью `1`)
```php
mm_hideFields('alias,link_attributes,template,menuindex,searchable,cacheable', '!1');
```

### Вывод превью для TV-полей типа «Изображение»
```php
mm_widget_showimagetvs();
```
