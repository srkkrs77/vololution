# Сниппет cookieConsent (GDPR / TTDSG)

**Версия:** 1.1.0
**Назначение:** Вывод баннера согласия на использование cookie в соответствии с законодательством ЕС (GDPR / TTDSG).
**Зависимости:** Требуется патч ядра `index.php` (отложенный старт сессии), чтобы до клика по баннеру сайт не устанавливал cookie.

## 1. Как это работает
1. Сниппет выводит HTML-разметку баннера, CSS-стили и JavaScript-код.
2. Скрипт проверяет `localStorage` браузера. Если согласие уже было дано (и не истекло 180 дней), баннер не показывается.
3. Если согласия нет — баннер плавно появляется через 0.8 секунды.
4. Выбор пользователя (принять всё / только необходимые / настроить) сохраняется в `localStorage` под ключом `sm_cookie_consent`.
5. Если пользователь дает согласие на категории, которые ранее были отклонены, страница перезагружается (`location.reload()`), чтобы применить настройки.

## 2. Мультиязычность
Сниппет автоматически определяет язык страницы по URL (первому сегменту пути):
- `/de/` → Немецкий
- `/ru/` → Русский
- `/fr/` → Французский
- `/es/` → Испанский
- `/it/` → Итальянский
- `/en/` или без префикса → Английский (по умолчанию)

*Если язык не найден, берется английский.*

## 3. Установка и вызов
Вызывать сниппет нужно **один раз** на странице, лучше всего перед закрывающим тегом `</body>` (например, в чанке `footer.tpl`).
