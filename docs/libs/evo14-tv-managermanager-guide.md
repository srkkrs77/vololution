# Шпаргалка по TV-параметрам и ManagerManager в Evolution CMS 1.4 (VoloLution CMS)

Руководство по созданию дополнительных полей (TV), их переносу на нужные вкладки или в конкретные места формы редактирования документа (например, сразу под поле `description`) и выводу в шаблонах.

---

## 1. Где лежат правила ManagerManager и как это устроено

В Evolution CMS 1.4 (и сборке VoloLution CMS) за настройку внешнего вида формы документа отвечает плагин **ManagerManager**.

1. Перейдите в админке: **Элементы → Управление элементами → Плагины → ManagerManager → вкладка «Конфигурация»**.
2. Посмотрите параметр **`Configuration Chunk`**:
   * Если указано имя чанка (например, **`mm_rules`**) — плагин игнорирует файлы на сервере (`mm_rules.inc.php`) и читает правила **только из этого чанка** в админке (**Элементы → Чанки → `mm_rules`**).
   * Чанк `mm_rules` выполняется как PHP-код **без открывающего тега `<?php`** в начале, а вывод пользовательского JS/CSS в него делается через обычный `echo '<script>...</script>';`.

---

## 2. Пошаговая инструкция: создание TV и перенос под поле «Описание» (`description`)

### Шаг 1. Создание TV-параметров
1. Откройте: **Элементы → Управление элементами → Параметры (TV) → Новый параметр**.
2. Заполните:
   * **Имя параметра:** латиницей без пробелов (например, `slider-title-1`, `slider-title-2` и т.д.).
   * **Заголовок:** понятное название для контент-менеджера.
   * **Тип ввода:** `Текст`, `Текстовая область`, `Изображение` и др.
3. В блоке **Доступ шаблонов** отметьте галочкой нужные шаблоны (например, `home`) и нажмите **Сохранить**.

*(По умолчанию после этого поля появятся в самом низу вкладки «Общие» под редактором TinyMCE в разделе «Параметры (TV)»).*

---

### Шаг 2. Перенос TV-параметров строго под «Описание» (`description`)

Штатная функция `mm_moveFieldsToTab` умеет переносить TV только на другую вкладку целиком, но **не умеет** ставить их после конкретного стандартного поля на вкладке «Общие».

Чтобы поставить поля сразу под `description`, откройте чанк **`mm_rules`** (**Элементы → Чанки → `mm_rules`**) и вставьте **в самый конец чанка** следующий код:

```php
// --- Перенос TV под поле description ---
echo '<script>
document.addEventListener("DOMContentLoaded", function() {
    var descInput = document.querySelector("[name='description']");
    if (!descInput) return;
    var target = descInput.closest(".form-row, .row, tr");
    
    // Указываем имена TV в ОБРАТНОМ порядке (снизу вверх),
    // чтобы в админке они выстроились сверху вниз: 1 -> 2 -> 3 -> 4
    ["slider-title-4", "slider-title-3", "slider-title-2", "slider-title-1"].forEach(function(name) {
        var elems = document.querySelectorAll("small, span, label, div");
        for (var i = 0; i < elems.length; i++) {
            if (elems[i].textContent.trim() === "[*" + name + "*]") {
                var row = elems[i].closest(".form-row, .row, tr");
                if (row && target && row !== target) {
                    target.parentNode.insertBefore(row, target.nextSibling);
                }
                break;
            }
        }
    });
});
</script>' . "
";
```

#### Системные имена стандартных полей (если нужно вставить после другого поля):
Замените `description` в строке `querySelector("[name='description']")` на нужное имя:
* `pagetitle` — Заголовок
* `longtitle` — Расширенный заголовок
* `description` — Описание
* `alias` — Псевдоним
* `introtext` — Аннотация
* `menutitle` — Пункт меню

## 3. Альтернативные штатные варианты в чанке `mm_rules`

Если не нужно встраивать поля в середину вкладки «Общие», используйте встроенные функции ManagerManager (вставляются в чанк `mm_rules` без тегов `<script>`).

### Вариант А: Вынести поля на отдельную вкладку (как вкладка SEO)
```php
// 1. Создаем новую вкладку: ('Заголовок вкладки', 'id_вкладки', 'роли', 'id_шаблонов')
mm_createTab('Слайдер', 'slider_tab', '', '');

// 2. Переносим в нее нужные TV-параметры через запятую
mm_moveFieldsToTab(
    'slider-title-1,slider-title-2,slider-title-3,slider-title-4',
    'slider_tab',
    '',
    ''
);
```
*Примечание: Если вкладка нужна только для конкретного шаблона (например, с ID `5`), укажите `'5'` четвертым параметром в обеих функциях.*

### Вариант Б: Скрыть ненужные стандартные поля для всех или для конкретной роли
```php
// Скрыть поля longtitle и introtext для роли с ID 3 (например, контент-менеджер)
mm_hideFields('longtitle,introtext', '3');

// Скрыть поле для всех, кроме администраторов (роль !1)
mm_hideFields('link_attributes', '!1');
```

### Вариант В: Переименовать стандартное поле или добавить подсказку
```php
// Переименовать поле introtext в "Краткий анонс"
mm_renameField('introtext', 'Краткий анонс');

// Добавить поясняющий текст под полем description
mm_changeFieldHelp('description', 'Рекомендуемая длина — 140–160 символов');
```

### Вариант Г: Включить превью для TV типа «Изображение» и теги
```php
// Показывать миниатюры картинок у всех TV типа Image
mm_widget_showimagetvs();

// Превратить текстовое поле в удобный ввод тегов через запятую
mm_widget_tags('seo_keywords', ',');
```

## 4. Как вывести созданные TV-параметры на сайте

### 1. Прямой вывод на текущей странице (в шаблоне или чанке)
```html
<h1>[*slider-title-1*]</h1>
<p>[*slider-title-2*]</p>
```

### 2. Вывод TV другой страницы (например, с главной ID `1`)
Используйте сниппет `DocInfo` или `getField`:
```html
[[DocInfo? &docid=`1` &field=`slider-title-1`]]
```

### 3. Вывод TV внутри списков `DocLister`
Обязательно укажите имена TV в параметре `&tvList`, а в шаблоне выводите с префиксом `tv.`:
```html
[[DocLister?
    &parents=`2`
    &tvList=`slider-title-1,slider-title-2`
    &tpl=`@CODE: <div>[+tv.slider-title-1+] — [+tv.slider-title-2+]</div>`
]]
```

## 5. Частые грабли и как их избежать

1. **Не ставьте `<?php` и `?>` в чанке `mm_rules`:** чанк уже выполняется внутри PHP-парсера плагина.
2. **Не используйте `$modx->Event->output(...)` без тегов `<script>` внутри `mm_rules`:** в сборке VoloLution CMS чанк `mm_rules` выводит код напрямую в HTML-поток (через `echo`), поэтому голый JS без `<script>` сломает верстку и соседние скрипты.
3. **Не забывайте привязывать TV к шаблону:** если у TV не стоит галочка во вкладке «Доступ шаблонов», он не появится на странице редактирования документа, даже если прописан в `mm_rules`.
