# 🌐 CE (Community Edition) — экосистема

VoloLution CMS базируется на **Community Edition** Evolution CMS — форке, который активно поддерживается сообществом.

---

## Ядро

**Репозиторий:** `github.com/evocms-community/evolution`

**Последний релиз:** CE 1.4.37 — 13.11.2025

**Статус веток:**
- **CE 1.4.x** — активно развивается сообществом.
- **Официальная 1.4 (evo.im)** — только security fixes, заморожена.

**Совместимость:**
- Extras из официального репозитория совместимы с CE.
- Пакеты работают без изменений.

## Мониторинг безопасности

**Источники:**
- **GitHub:** `github.com/extras-evolution/security-fix` — официальные патчи безопасности.
- **Базы CVE:** `opencve.io`, `attackerkb.com` — мониторинг новых уязвимостей.
- **Релизы CE:** проверка новых версий в `evocms-community/evolution`.

**Частота проверки:** раз в месяц.

---

## План реагирования на уязвимость

1. **Проверить релизы CE** — возможно, уже выпущено исправление.
2. **Проверить коммиты** в `evocms-community/evolution` — возможно, фикс без релиза.
3. **Спросить в Telegram** `@evo_cms` — Pathologic и другие разработчики отвечают быстро.
4. **Тест патча** на тестовом сайте `vol.test`.
5. **Внести в дистрибутив** + зафиксировать в `CHANGELOG.md` (раздел «Патчи безопасности»).

## Наша позиция

VoloLution CMS использует **CE — сознательный выбор**:

- Ветка активно поддерживается.
- Сообщество живое и отзывчивое.
- PHP 8.5 поддерживается (частично + наши патчи).
- Extras совместимы.

Мы не форкаем и не создаём свою CMS. Мы **модернизируем** существующую сборку до современного уровня.
