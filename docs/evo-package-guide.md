# 📦 ИНСТРУКЦИЯ: СБОРКА ПАКЕТОВ ДЛЯ EVOLUTION CMS 1.4

Эта инструкция создана для того, чтобы больше никогда не тратить время на отладку установки пакетов. 
**ЗАПОМНИТЬ ГЛАВНОЕ:** Evo 1.4 — старая система, она не прощает ошибок в кодировке и структуре.

---

## 1. СТРУКТУРА ZIP-АРХИВА (КРИТИЧНО)

То, как должен выглядеть ZIP-архив, зависит от того, **куда** вы его ставите:

### А) Если ставите в наш VoloLution Store (наша сборка)
В корне ZIP-архива **ВСЕГДА** должны лежать только две папки:
- `assets/`
- `install/`

*(Наш Store мы переписали, и он умеет их правильно распаковывать).*

### Б) Если ставите на ЧИСТУЮ Evolution CMS 1.4 CE
Старый установщик Evo 1.4 устроен примитивно: он ищет в архиве **одну общую папку** и копирует её целиком в корень сайта. Если папок две (`assets` и `install`), он копирует только последнюю, а остальное теряет.

Для чистой Evo структура должна быть такой:
```text
имя_пакета/  <-- ОДНА общая папка (например, backup)
├── assets/
└── install/
```
## 2. Как правильно упаковать в Windows:

Зайти в папку сборки.

Выделить нужные папки (или одну общую папку, если это для чистой Evo).

ПКМ -> «Отправить» -> «Сжатая ZIP-папка».

## 3. КОДИРОВКА ФАЙЛОВ (ПРИЧИНА 99% ПРОВАЛОВ)
Файлы дескрипторов .tpl ОБЯЗАНЫ быть в кодировке UTF-8 (БЕЗ BOM).

Если сохранить с BOM (как часто делает Блокнот), Evo не увидит первую строчку //<?php и молча проигнорирует пакет.

Как правильно: В Notepad++ (или VS Code) выбрать «Кодировка» -> «UTF-8» (убедиться, что нет слова «BOM»). Сохранить.

## 4. ДЕСКРИПТОРЫ .tpl (ТОЧНЫЕ СТРОКИ)
Дескриптор — это "паспорт" пакета. Он лежит в install/assets/... и должен начинаться строго с //<?php (без пробела).

ЗАПРЕЩЕНО использовать setup.info.php для модулей, сниппетов и плагинов! Это файл только для установки ядра CMS. Он только путает установщик.

//<?php
/**
 * Название модуля
 *
 * @category    module
 * @version     1.0.0
 * @internal    @modx_category Manager and Admin
 * @internal    @disabled 0
 * @internal    @installset base
 */

include_once(MODX_BASE_PATH . 'assets/modules/имя/index.php');

## 4.2. Сниппет (лежит в install/assets/snippets/имя.tpl)
//<?php
/**
 * Название сниппета
 *
 * @category    snippet
 * @version     1.0.0
 * @internal    @modx_category Content
 * @internal    @installset base
 */

return require MODX_BASE_PATH.'assets/snippets/имя/snippet.имя.php';

## 5. ЧЕК-ЛИСТ ПЕРЕД СБОРКОЙ
□ Правильная структура ZIP (см. пункт 1: зависит от целевой системы).
□ Файлы .tpl сохранены в UTF-8 (без BOM).
□ Файл .tpl начинается строго с //<?php.
□ Указан @category (module, snippet, plugin).
□ Указан @internal @installset base.
